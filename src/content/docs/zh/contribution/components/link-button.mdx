```ts
linkButton({ label: '开始使用', href: '/guides/example/' });
```

```ts
linkButton({
  label: '查看 GitHub',
  href: 'https://github.com/CelPlume/CelestPlume',
  external: true,
  icon: '<svg …>…</svg>', // 任意内联 SVG 字符串
});
```

## 参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `href` | `string` | — | 目标地址（必填）。 |
| `label` | `string` | — | 按钮文本（必填）。 |
| `external` | `boolean` | `false` | 添加 `target="_blank" rel="noreferrer"`。 |
| `icon` | `string` | `''` | 置于文本前的原始 SVG 字符串。 |

## 注意

- 样式来自 `.cpd-btn cpd-btn-ghost cpd-link-button`；尺寸随周围排版继承。
- 图标可来自 `src/lib/ui/icons.ts` 的 Iconify 构建 SVG，或任意内联 SVG 字符串。
