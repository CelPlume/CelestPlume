Docs Kit 的每个组件都是一个**纯 TypeScript 函数**，返回 HTML 字符串；交互由
`initCelestialUI()` 在运行时通过 `data-cpd-*` 钩子接管。全部导出见
`src/lib/ui/index.ts`。

本分类每页记录一个组件：**不同状态的实时预览**、生成它们的构建器调用、
参数表与注意事项。

## 运行时

`initCelestialUI()` 通过事件委托接管全部交互，DOM 就绪后调用一次即可：

```ts
import { initCelestialUI } from '/src/lib/ui/runtime';
initCelestialUI();
```

它负责：侧边栏折叠分组/折叠/抽屉、ClerkTOC 追踪、标签页、折叠面板、复制
按钮与主题切换。函数幂等，任何页面调用都安全（无 `cpd-` 元素时为空操作）。
文档站通过 `astro.config.mjs` 里的 `celestialUiRuntime` 集成注入每个页面。

设计令牌见[样式规范](/zh/contribution/styles/)与 `src/lib/ui/tokens.ts`。
