`files()` 渲染 Plumest 风格文件树。目录是原生 `<details>` 元素，无需
JavaScript 即可折叠。

## 嵌套树

<Preview
  label="目录 + 文件"
  html={files([
    folder('<span>src</span>', { label: 'src' }),
    folder('<span>lib</span>', { label: 'lib' }),
    fileRow('ui'),
    fileRow('tokens.ts'),
    fileRow('components.ts'),
    fileRow('index.ts'),
  ])}
/>

```ts
files([
  folder('<span>src</span>', { label: 'src' }),
  folder('<span>lib</span>', { label: 'lib' }),
  fileRow('ui'),
  fileRow('tokens.ts'),
  fileRow('components.ts'),
  fileRow('index.ts'),
]);
```

```ts
files([
  fileRow('package.json', '<svg …>…</svg>'), // 任意内联 SVG 字符串
  fileRow('README.md'),
]);
```

## API

| 函数 | 签名 | 说明 |
| --- | --- | --- |
| `file(name, icon?)` | `(string, string?) => string` | 文件行（可传自定义 SVG 图标）。 |
| `folder(children, { label, defaultOpen? })` | — | 可折叠目录行。 |
| `files(children)` | `(string) => string` | 树容器。 |

## 注意

- `folder(children, …)` 的 label 接收**预构建 HTML**，便于独立样式化目录名。
- 每层子项按一个 `--cpd-spacing` 步长缩进。
