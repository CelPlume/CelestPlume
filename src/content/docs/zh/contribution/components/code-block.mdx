`codeBlock()` 渲染带框代码图，可选文件名头与 ghost 复制按钮。复制按钮由
运行时接线（`[data-cpd-copy]`）。

## 参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `code` | `string` | — | 代码文本（必填）。 |
| `filename` | `string` | `''` | 文件名头——同时启用复制按钮。 |
| `lang` | `string` | `''` | 语言提示类（`language-<lang>`），不做语法高亮。 |

## 注意

- 构建器会转义 `code`——原始标记永不执行。
- Kit 不内置语法高亮；真实文档页改用 astro-expressive-code 块（样式已对齐）。
- 复制使用 `navigator.clipboard`，带 `execCommand('copy')` 回退。
