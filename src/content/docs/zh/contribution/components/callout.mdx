Callout 在正文旁呈现提示信息。每种 `type` 对应一个语义令牌
（`--cpd-info`、`--cpd-warning` 等），驱动左侧条、`color-mix` 底色与默认图标。

## 变体

callout('对读者有帮助的补充说明。', { type: 'info', title: '注意' });

## 参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `content` | `string` | — | 正文文本（必填，第一个参数）。 |
| `type` | `'info' \| 'warning' \| 'error' \| 'success' \| 'idea'` | `'info'` | 语义变体——驱动左侧条、底色与图标。 |
| `title` | `string` | `''` | 可选的加粗标题。 |
| `icon` | `string` | 自动 | 替换默认图标的原始 SVG 字符串。 |

## 注意

- `content` 内的 Markdown 会被转义；需要富文本时请传入 HTML。
- 底色由 `color-mix(in oklab, var(--cpd-<type>) 10%, transparent)` 生成——
  每种变体单一语义令牌，与 Plumest 一致。
