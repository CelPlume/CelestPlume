`steps` 渲染编号流程。编号来自 CSS 计数器（Plumest 风格圆形徽标），左侧
竖线连接各步骤。

## 三步

<Preview
  label="字符串数组"
  html={steps([
    step(`先用 ${code('bun install')} 安装依赖。`),
    step(`运行 ${code('bun run dev')}，打开 http://localhost:4321。`),
    step(`在 ${code('src/content/docs/')} 下编写文档。`),
  ])}
/>

```ts
steps([
  step(`先用 ${code('bun install')} 安装依赖。`),
  step(`运行 ${code('bun run dev')}，打开 http://localhost:4321。`),
  step(`在 ${code('src/content/docs/')} 下编写文档。`),
]);
```

## 两步、预构建 HTML

<Preview
  label="单个 HTML 字符串"
  html={steps(
    '<div class="cpd-step">创建一个分支。</div><div class="cpd-step">提交 Pull Request。</div>',
  )}
/>

```ts
steps(
  '<div class="cpd-step">创建一个分支。</div><div class="cpd-step">提交 Pull Request。</div>',
);
```

## 注意

- `steps(children)` 接受 `string[]`（每个条目自动包进 `.cpd-step`）或单个 HTML 字符串。
- `step(content)` 是用于包裹数组条目的单步构建器。
