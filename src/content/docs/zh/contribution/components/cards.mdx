`card()` 构建单张卡片；`cards()` 将任意数量卡片包进 Plumest 风格响应式网格。
富信息链接卡片（仓库、视频）请使用下方的 `GitHubCard` / `GitHubCards` /
`BilibiliCard`。

- 图标经项目本地 `@iconify-json` 图标集解析——运行时绝不从 Iconify API 在线拉取。

## GitHub 仓库卡片

`GitHubCard` 渲染单张 GitHub 仓库卡片；`GitHubCards` 渲染网格（双列）或整行
堆叠。整卡为链接，标题显示 `owner/repo`。描述、语言与 star/fork 数在构建期
抓取 GitHub API，并在浏览器中实时刷新。

### 单个

独立卡片上限 `480px`，水平居中。

<GitHubCard owner="CelPlume" repo="CelestPlume" />

```astro
---
import GitHubCard from '../../../../../components/kit/GitHubCard.astro';
---

<GitHubCard owner="CelPlume" repo="CelestPlume" />
```

### 网格（双列）

`GitHubCards` 把任意数量的卡片渲染进响应式双列网格；同一行的卡片取最高者
等高。

<GitHubCards
  items={[
    { owner: 'CelPlume', repo: 'CelestPlume' },
    { owner: 'CelPlume', repo: 'BookmarkHarbor' },
  ]}
/>

```astro
---
import GitHubCards from '../../../../../components/kit/GitHubCards.astro';
---

<GitHubCards
  items={[
    { owner: 'CelPlume', repo: 'CelestPlume' },
    { owner: 'CelPlume', repo: 'BookmarkHarbor' },
  ]}
/>
```

### 整行堆叠

传入 `layout="stack"` 让每行一张卡片，铺满整行宽度。

<GitHubCards items={[{ owner: 'CelPlume', repo: 'squoosh' }]} layout="stack" />

```astro
---
import GitHubCards from '../../../../../components/kit/GitHubCards.astro';
---

<GitHubCards items={[{ owner: 'CelPlume', repo: 'squoosh' }]} layout="stack" />
```

### GitHub 卡片参数

`GitHubCard` 接受一组选项；`GitHubCards` 接受 `items`（同样的选项组成的数组）
以及可选的 `layout`。

<PropsTable
  labels={{ prop: '选项', type: '类型', default: '默认值' }}
  type={{
    owner: { type: 'string', description: '仓库所有者（用户或组织）。' },
    repo: { type: 'string', description: '仓库名称。' },
    target: { type: 'string', default: "'_blank'", description: '仓库链接的打开方式。' },
    auth: { type: 'string', default: "''", description: '构建期请求使用的 GitHub token。' },
    layout: { type: "'grid' | 'stack'", default: 'grid', description: '仅 <code>GitHubCards</code>：双列或每行一卡。' },
  }}
/>

注意：

- 整卡链接到仓库；标题显示 `owner/repo`。
- 构建期数据来自 GitHub REST API；请求失败时渲染为纯链接卡片。
- star/fork 数与缺失的元数据在浏览器中刷新，并缓存于 `localStorage`
  以遵守 API 限流。
- 构建与运行时都需要能访问 `api.github.com`。

## Bilibili 链接卡片

`BilibiliCard` 把 Bilibili 视频渲染为链接卡片：封面、标题、简介与 UP主。
元数据在构建期经 Bilibili view API 抓取；请求失败时退化为纯链接卡片。

<BilibiliCard bvid="BV1fK4y1s7Qf" />

```astro
---
import BilibiliCard from '../../../../../components/kit/BilibiliCard.astro';
---

<BilibiliCard bvid="BV1fK4y1s7Qf" />
```

### Bilibili 卡片参数

<PropsTable
  labels={{ prop: '选项', type: '类型', default: '默认值' }}
  type={{
    bvid: { type: 'string', required: true, description: 'Bilibili 视频 BV 号。' },
    target: { type: 'string', default: "'_blank'", description: '视频链接的打开方式。' },
  }}
/>

注意：

- 封面、头像与外链箭头带 `referrerpolicy="no-referrer"`，避免 Bilibili
  图床因 Referer 拒绝服务。
- 非法 `bvid` 会让构建直接报错。
- 可播放嵌入请见[嵌入媒体](/zh/contribution/components/embed-media/)。
