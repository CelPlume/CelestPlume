## 参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `title` | `string` | — | 卡片标题（必填）。 |
| `description` | `string` | `''` | 说明文字。 |
| `href` | `string` | `''` | 目标地址——带它时卡片渲染为 `<a>`。 |
| `external` | `boolean` | `false` | 添加 `target="_blank" rel="noreferrer"`。 |
| `icon` | `string` | `''` | Iconify 图标名（如 `lucide:zap`）或原始 SVG。 |
| `children` | `string` | `''` | 说明下方的额外 HTML。 |

## 注意

- 图标经项目本地 `@iconify-json` 图标集解析——运行时绝不从 Iconify API 在线拉取。
- `cards()` 接受 `CardOptions[]` 或单个预构建 HTML 字符串。
