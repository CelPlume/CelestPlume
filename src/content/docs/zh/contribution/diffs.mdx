代码块通过 Expressive Code 的 text markers 支持 git 风格的差异高亮。
三种语法覆盖全部场景：`diff` 语言围栏、行级 `ins=`/`del=` 标记、词级标记。
标记色由 Plumest 色系自动派生，深浅色自适应。

## Diff 语言

围栏语言写 `diff`，以 `-`/`+` 开头的行获得删除/新增样式。附加常规语言
可以保留语法高亮：

```diff lang="ts"
  function greet(name: string) {
-   return "Hello, " + name;
+   return `Hello, ${name}!`;
  }
```

````md
```diff lang="ts"
  function greet(name: string) {
-   return "Hello, " + name;
+   return `Hello, ${name}!`;
  }
```
````

## 行级标记

`ins={}` / `del={}` 在任意语言中标记新增/删除的行，可附带标签 ——
适合"改前 vs 改后"场景，不必伪造 diff 围栏：

```ts ins={"新":2} del={"旧":4}
const retries = 3;
const cache = new Map();
const TIMEOUT_MS = 5000;
const CACHE_SIZE = 100;
```

````md
```ts ins={"新":2} del={"旧":4}
const retries = 3;
const cache = new Map();
const TIMEOUT_MS = 5000;
const CACHE_SIZE = 100;
```
````

## 词级标记

用引号包住词语即可高亮全部出现位置；`ins=` / `del=` 在行内标记新增或
删除的词：

```js "retries" ins="attempts" del="retries"
const retries = readConfig().attempts;
log(`retrying, ${retries} attempts left`);
```

## 高亮标记

`{行号}` 对整行或区间做中性高亮：

```ts title="config.ts" {2-3}
const retries = 3;
const cache = new Map();
const TIMEOUT_MS = 5000;
```

## 主题

标记色由 `astro.config.mjs` 中的 LCH 色相令牌驱动
（`markHue: 82`、`insHue: 150`、`delHue: 25`），对齐 Plumest 的
淡金 / 成功绿 / 错误红色相。背景、边框与指示符按主题自动派生，
无需任何 CSS 覆盖。
