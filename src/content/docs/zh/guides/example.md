## 欢迎

欢迎来到 **CelestPlume** —— 一个使用
[Astro](https://astro.build/) 与 [Starlight](https://starlight.astro.build/)
构建、并以 **CelestPlume Docs Kit**（纯 TypeScript、无 React）重新着色的
Plumest 风格双语文档站点。

可见外壳——侧边栏、ClerkTOC、文章与组件——全部来自 `src/lib/ui/` 的 Kit；
Starlight 负责底层路由、i18n、搜索与 sitemap。Kit 的样式与组件参考见
[贡献](/zh/contribution/overview/) 分类。

本站提供两种语言：

- English
- 简体中文

使用顶部导航栏中的语言切换器可以切换语言。
