Code blocks support git-style diff highlighting through Expressive Code's
text markers. Three syntaxes cover every case: `diff` language fences,
per-line `ins=`/`del=` markers and word-level marks. Colors derive from the
Plumest palette automatically in light and dark themes.

## Diff language

Use `diff` as the fence language; lines prefixed with `-` or `+` get
removed/added styling. Attach a regular language to keep syntax highlighting:

```diff lang="ts"
  function greet(name: string) {
-   return "Hello, " + name;
+   return `Hello, ${name}!`;
  }
```

````md
```diff lang="ts"
  function greet(name: string) {
-   return "Hello, " + name;
+   return `Hello, ${name}!`;
  }
```
````

## Line markers

`ins={}` / `del={}` mark added/removed lines in any language, with optional
labels — useful for "before vs after" without a fake diff fence:

```ts ins={"new":2} del={"old":4}
const retries = 3;
const cache = new Map();
const TIMEOUT_MS = 5000;
const CACHE_SIZE = 100;
```

````md
```ts ins={"new":2} del={"old":4}
const retries = 3;
const cache = new Map();
const TIMEOUT_MS = 5000;
const CACHE_SIZE = 100;
```
````

## Word marks

Quote a word to highlight every occurrence; `ins=` / `del=` mark added or
removed words inline:

```js "retries" ins="attempts" del="retries"
const retries = readConfig().attempts;
log(`retrying, ${retries} attempts left`);
```

## Marks

`{lines}` highlights a neutral mark on whole lines or ranges:

```ts title="config.ts" {2-3}
const retries = 3;
const cache = new Map();
const TIMEOUT_MS = 5000;
```

## Theming

Marker colors are driven by LCH hue tokens in `astro.config.mjs`
(`markHue: 82`, `insHue: 150`, `delHue: 25`), aligned with the Plumest gold /
success / error hues. Backgrounds, borders and indicators derive per theme —
no CSS overrides needed.
