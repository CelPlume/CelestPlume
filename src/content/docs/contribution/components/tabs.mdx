Tabs switch panels client-side via the runtime — no page reload. The tab list
is `role="tablist"` with proper `aria-selected` state.

## Simple items

<Preview
  label="Items only"
  html={tabs({ items: ['Preview', 'Code', 'Notes'] })}
/>

```ts
tabs({ items: ['Preview', 'Code', 'Notes'] });
```

tabs({

## Props

<PropsTable
  labels={{ prop: 'Option', type: 'Type', default: 'Default' }}
  type={{
    items: { type: 'string[]', description: 'Tab titles when <code>panels</code> is omitted.' },
    panels: { type: 'TabPanel[]', description: '<code>{ title?, value?, content }</code> — content can be HTML.' },

    defaultIndex: { type: 'number', default: '0', description: 'Initially active tab.' },
  }}
/>

## Notes

- `value` (when set) is used as the `data-cpd-tab` value; otherwise it is
  derived from the title (`title.toLowerCase().replace(/\s/, '-')`).
- Panels with no content (items-only mode) render an empty active panel.
