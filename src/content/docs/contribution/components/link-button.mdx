```ts
});
```

## Props

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `href` | `string` | — | Target URL (required). |
| `label` | `string` | — | Button text (required). |
| `external` | `boolean` | `false` | Adds `target="_blank" rel="noreferrer"`. |
| `icon` | `string` | `''` | Raw SVG string placed before the label. |

## Notes

- Styling comes from `.cpd-btn cpd-btn-ghost cpd-link-button`; sizes inherit
  from the surrounding typography.
- Use Iconify-built SVGs from `src/lib/ui/icons.ts` or any inline SVG string.
