Pagination renders Plumest-style previous/next cards. Either side can be
omitted; labels localize the "Previous Page" / "Next Page" hints.

## Both sides

<Preview
  label="Previous + next"
  html={pagination(
    { title: 'Styles', description: 'Tokens and layout metrics.', href: '/contribution/styles/' },
    { title: 'Cards', description: 'The link-card grid.', href: '/contribution/components/cards/' },
  )}
/>

```ts
pagination(
  { title: 'Styles', description: 'Tokens and layout metrics.', href: '/contribution/styles/' },
  { title: 'Cards', description: 'The link-card grid.', href: '/contribution/components/cards/' },
);
```

## One side only

## Props

<PropsTable
  labels={{ prop: 'Option', type: 'Type' }}
  type={{
    previous: { type: 'PaginationItem | undefined', description: 'Previous card; omit to hide.' },
    next: { type: 'PaginationItem | undefined', description: 'Next card; omit to hide.' },
    'labels.previous / labels.next': { type: 'string', description: 'Localized hint labels.' },
  }}
/>

`PaginationItem`: `{ title: string; description?: string; href: string }`.

## Notes

- On the real docs pages the Starlight `Pagination` slot is overridden with
  this builder; labels are localized automatically from the current locale.
