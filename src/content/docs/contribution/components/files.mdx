import { files, folder, file as fileRow } from '../../../../lib/ui';

`files()` renders a Plumest-style file tree. Folders are native `<details>`
elements, so they collapse without JavaScript.

## Nested tree

<Preview
  label="Folders + files"
  html={files([
    folder('<span>src</span>', { label: 'src' }),
    folder('<span>lib</span>', { label: 'lib' }),
    fileRow('ui'),
    fileRow('tokens.ts'),
    fileRow('components.ts'),
    fileRow('index.ts'),
  ])}
/>

```ts
files([
  folder('<span>src</span>', { label: 'src' }),
  folder('<span>lib</span>', { label: 'lib' }),
  fileRow('ui'),
  fileRow('tokens.ts'),
  fileRow('components.ts'),
  fileRow('index.ts'),
]);
```

## API

| Function | Signature | Description |
| --- | --- | --- |
| `file(name, icon?)` | `(string, string?) => string` | A file row (custom SVG icon optional). |
| `folder(children, { label, defaultOpen? })` | — | A collapsible folder row. |
| `files(children)` | `(string) => string` | The tree container. |

## Notes

- `folder(children, …)` takes **pre-built HTML** for its label span, allowing
  independent styling of the folder name.
- Folder rows with children are indented by one `--cpd-spacing` step per level.
