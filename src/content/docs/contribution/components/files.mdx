import Preview from '../../../../components/kit/Preview.astro';
import { files, folder, file as fileRow } from '../../../../lib/ui';

`files()` renders a file tree: folder rows toggle with a rotating chevron,
folder icons swap between open/closed states, and child rows sit on an
indent line (`lines: false` hides the guides).

## Simple tree

<Preview
  label="Folders + files"
  html={files(
    folder(fileRow('src') + fileRow('lib') + fileRow('ui'), { name: 'src' }) +
      folder(fileRow('tokens.ts') + fileRow('components.ts'), { name: 'lib' }),
  )}
/>

```ts
files(
  folder(fileRow('src') + fileRow('lib') + fileRow('ui'), { name: 'src' }) +
    folder(fileRow('tokens.ts') + fileRow('components.ts'), { name: 'lib' }),
);
```

## API

| Function | Signature | Description |
| --- | --- | --- |
| `file(name, icon?)` | `(string, string?) => string` | A file row (custom SVG icon optional). |
| `folder(children, { name, defaultOpen?, icon?, openIcon? })` | — | A collapsible folder row; the icon swaps to `openIcon` when open. |
| `files(children, { lines? })` | — | The tree container; `lines: false` hides the indent guides. |

## Notes

- Folder rows are buttons wired by the runtime (`data-cpd-folder-toggle`),
  not native `<details>`.
- `folder()` takes pre-built HTML for its children; nest folders freely for
  deeper trees.
