## ChronoSync

ChronoSync (时序同笺) is a timetable and schedule management tool designed for
Shandong Normal University students.

## Features

- One-click import from the academic affairs system
- ICS export for subscribing on multi-platform calendars
- Personal profiles, team views, and an admin panel
- Front-end and back-end separated for easy extension
