## BookmarkHarbor

BookmarkHarbor is a local-first, open-source bookmark browser with folders,
tags, a modern UI, and multilingual support.

## Features

- Organize bookmarks with folders and tags
- Local storage keeps your data safe and private
- Manage bookmarks like a file manager
- Modern, multilingual interface
