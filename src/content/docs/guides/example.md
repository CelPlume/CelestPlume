## Welcome

Welcome to **CelestPlume** — a bilingual documentation site built with
[Astro](https://astro.build/) and [Starlight](https://starlight.astro.build/),
restyled with the Plumest-inspired **CelestPlume Docs Kit**
(pure TypeScript, no React).

The visible chrome — sidebar, ClerkTOC, article and components — comes from
the kit in `src/lib/ui/`; Starlight handles routing, i18n, search and the
sitemap underneath. See the [Contribution](/contribution/overview/) category
for the kit's styles and component reference.

This site is available in two languages:

- English
- 简体中文

Use the language switcher in the top navigation bar to change languages.
